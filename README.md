# cliptoken

Clip and reshape token text streams with deterministic transforms.

**Site:** https://theworker02.github.io/cliptoken/

## Install / run

```bash
git clone https://github.com/theworker02/cliptoken.git
cd cliptoken
node src/cli.js
node --test
```
